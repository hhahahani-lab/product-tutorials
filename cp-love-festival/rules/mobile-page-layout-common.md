# 移动端页面布局通用约定

- 标识：mobile-page-layout-common
- 产品：Yaloka / MeMe；适用于移动端 App／H5 活动页及其浏览器交互原型。
- 状态：2026-10-26 用户明确确认的设计默认约定；不代表已上线。
- 来源：邀请活动原型讨论，用户确认页面应占满可视屏幕、内容内部滚动，并要求后续复用。

## 后续页面默认执行（2026-10-30 用户确认）

- 后续新建和修改移动端页面、H5及交互原型，默认遵循本规范和对应平台的组件规范；用户不必逐次重申。
- 先按用途选择确认弹窗、说明弹窗、表单弹窗、底部抽屉、操作菜单或二级页面，再确定退出方式，不机械为所有弹层添加 × 或套用同一高度。
- 固定可视区域、正文内部滚动、设备安全区、操作可达、信息简洁、多语言适配及退出后恢复均作为交付默认检查项。
- 项目明确的例外单独记录：邀请活动记录抽屉固定半屏、分享海报抽屉无 ×，不泛化为所有项目的通用要求。

## 页面容器

- 页面容器占满当前设备可视区域，高度不随内容增长，不因切换 Tab 或进入二级页忽长忽短。
- 适配动态视口与安全区，不将正式移动端页面写死为某个像素高度；桌面浏览器的手机预览可使用稳定模拟视口，但各页面必须一致。
- 顶部导航固定，正文在剩余区域内滚动；避免整页和正文形成重复滚动。
- 隐藏滚动条但保留触摸、鼠标及键盘滚动能力。

## 底栏与弹窗

- 有固定底栏的页面，将其固定在当前页面可视区域底部，正文预留足够空间，不遮挡最后一条内容。
- 邀请活动 Inviter 的 Invite Friends 按钮固定在底部上方；Ranking 的 My 区域固定底部，与页面同宽。其他页面按自身功能配置底栏，不机械增加。
- 弹窗或抽屉限制在可视范围内，内容超长时内部滚动，标题及关闭操作保持可达；具体比例与关闭方式按对应场景规范。

### 移动端弹层组件选择与退出（2026-10-30）

| 组件用途 | 默认退出入口 | 遮罩与手势 |
|---|---|---|
| 确认／警告 | 取消、确认或具体操作按钮，不重复加关闭图标 | 重要决策不依赖点击遮罩退出，关闭不执行确认动作 |
| 简短告知 | 知道了／确定；无底部按钮时可用关闭图标 | 根据内容允许遮罩关闭 |
| 居中自定义说明／内容弹窗 | 明确的关闭图标 | 可用遮罩辅助关闭 |
| 填写表单 | 取消和提交；已有取消不再叠加关闭图标 | 防止误触遮罩丢失输入，退出后的草稿处理由业务明确 |
| 底部抽屉 | 下滑、遮罩、系统返回；复杂操作可提供显式关闭 | 高度按业务配置，不能统一认定为半屏或禁止关闭按钮 |
| 底部操作菜单 | 选择操作或取消 | 不重复堆放关闭图标 |
| 全屏模态流程 | 取消／关闭及完成；步骤返回与退出流程区分 | 不依赖遮罩退出 |
| Toast | 自动消失 | 不加关闭图标 |

- 同一弹层保留清楚的主要退出方式；关闭不隐含提交或保存。
- 原型支持 Escape、焦点限制和关闭后焦点恢复；背景不可误操作，内层关闭不连带关闭外层。
- 参考 [Apple Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)、[Material Bottom sheets](https://m1.material.io/components/bottom-sheets.html)。表中是本产品采用的组件默认约定，具体业务可覆盖。

### 记录抽屉与说明弹窗（2026-10-29 补充）

- 遮罩只覆盖当前活动页面／手机预览容器，不延伸到桌面页面外围。
- 本活动记录抽屉从当前页面底部覆盖打开，高度固定为当前页面可视高度的 1/2，包含抽屉内底部安全区留白；内容内部滚动，少量／空记录也不改变高度，背景保留原位置。
- 记录抽屉右上角不放关闭图标；点击遮罩、下滑收起或点击顶部拖拽条关闭，键盘 Escape 可关闭。关闭恢复原页面位置。
- 本活动分享海报使用底部抽屉，不放 ×；以顶部拖拽条、下滑、点击遮罩及 Escape 关闭。海报抽屉按海报与渠道内容适配高度，不套用记录抽屉的50%高度。
- 居中问号说明弹窗与记录抽屉分开：说明弹窗按内容确定高度并限制在页面内，可保留关闭入口。
- 模拟状态按用户可见的不同操作与结果划分；纯后台发奖待处理／失败不各设一个新人页面状态，后台仍保留重试和入账状态。
- 2026-11-02 用户确认的长期默认：状态优先复用、简洁、合并。布局和可执行操作相同的场景共用一个页面状态，不按每个原因新增状态；模拟选项用括号简述包含的场景。
- 资格校验失败属于操作结果，待发、失败、封顶属于对应任务或记录的结果，不因此另建整页状态；只有页面布局或可执行操作确实不同，才拆分状态。必要的后台业务状态继续保留。

## 信息简洁与多语言

- 2026-10-29 用户明确要求长期复用：以易学、简洁为默认，兼顾多语言，避免重复入口、重复提示与额外状态文字。
- 图形已经清楚表达的信息不重复加文字；进度条优先用填充、节点和勾选表达进度，不机械附加“已达标／未达标”或“3/9”等计数。
- 首页保留判断与操作必需的信息，条件、计算方式、期限及上限等必要说明放入任务标题后的问号入口；不隐藏必须当场知晓的错误或限制。
- 同一操作保留清晰的主要入口，不在每张任务卡重复同一引导。后台处理状态不直接全部搬到前台。
- 图标、数字及短标签优先复用；保留图标的无障碍名称，不能只靠颜色区分关键状态。布局为翻译后的长文案预留空间，不靠缩小字号或截断关键内容解决。

## 原型检查

- 检查首页、各 Tab、二级页和空状态使用一致的页面视口。
- 在首屏、中段和底部验证固定元素位置及最后一条内容可见性。
- 同时检查窄屏、短屏、长内容及弹窗，不能只在独立浏览器通过后就认定嵌入预览表现一致。
- 独立 HTML 导出含 iframe 时，外层 iframe 同样固定为浏览器可视高度，不使用内容测量结果不断增加 iframe 高度；导出后检查外层及各 Tab 的实际可视高度。
