# Weekly CP PRD

## 1. 活动配置

| 项目 | 配置 |
| --- | --- |
| 活动时间 | 待定 |
| 时区 | UTC+5 |
| 页面文案 | 英文 |
| 榜单周期 | 周榜、月榜 |
| 页面 Tab | Ranking、Love Gifts、Hall of Love |

- 活动以亲密关系为单位，展示双方头像和昵称，不展示 UID。

## 2. CP 榜单 Ranking

周榜统计当周活动值，月榜统计当月活动值。关系双方互赠的礼物合并计入该关系活动值；同一笔送礼可同时计入对应周榜和月榜。

礼物金币价值按以下规则计算为活动值：

| 礼物类型 | 活动值 |
| --- | --- |
| 常规礼物 | 礼物金币价值 × 100% |
| 幸运礼物 | 礼物金币价值 × 10% |
| 关系礼物（城堡、马车、玫瑰花、戒指、香水及线上其他关系礼物） | 礼物金币价值 × 配置倍率 |

关系礼物倍率仅影响本活动周榜、月榜。

| 榜单区域 | 展示内容 |
| --- | --- |
| Top3 | 名次、双方头像、双方昵称、活动值 |
| 其他名次 | 名次、双方头像、双方昵称、活动值 |
| My | 本人 CP 名次、双方头像、双方昵称、活动值 |

### 榜单奖励

Rewards 入口放在倒计时与榜单之间，靠右展示。打开后默认展示当前榜单周期，也可切换 Weekly、Monthly。

| 奖励 | 周榜 | 月榜 |
| --- | --- | --- |
| 关系卡 | Top1–3 | Top1–3 |
| CP 头像框 | Top1–3 | Top1–3 |
| 徽章 | Top1–3 | Top1–3 |
| 座驾 | Top1–3 | Top1–3 |
| Banner | Top1，展示关系双方 | Top1，展示关系双方 |
| 开屏页 | — | Top1，展示关系双方 |

### 关系变更

- 关系解除后，该关系在当前周榜、月榜及 Love Gifts 当前周期的活动值清零。
- 已发放的奖励不追回，尚未发放的奖励取消。
- 重新建立关系或建立新关系后，活动值从 0 开始累计。

## 3. 活动礼物 Love Gifts

指定关系礼物（城堡、马车、玫瑰花、戒指、香水）合并统计关系双方互赠的礼物金币价值，按 100% 计算活动值，每款礼物分别计算 Top1 CP。

- 支持查看当前周期及最近 1 个月内已结算的礼物周期；当前周期显示倒计时。
- 默认选中首个礼物；点击其他礼物卡片后同步选中并打开大图。
- 礼物大图展示礼物、对应周期 Top1 双方、活动值和周期。

### 当前周期底栏

底栏仅在当前礼物周期展示，内容跟随选中的礼物：

- 本人存在多段关系时，按活动值展示最高一段关系；同分顺序沿用活动榜单通用规则；
- 双方头像和昵称；
- 该关系本期累计活动值。

点击底栏打开抽屉，按页面顺序查看全部活动礼物。

### 曝光奖励

Love Gifts 页面提供 Rewards 入口，展示两项权益：

| 权益 | 展示规则 |
| --- | --- |
| 活动页曝光 | 每款礼物当前周期 Top1 CP 展示在对应礼物卡片和大图 |
| 礼物面板曝光 | 选中活动礼物时展示该礼物上周已结算 Top1 CP Banner |

客户端礼物面板只写逻辑，不制作 Demo：

- Banner 按选中的礼物 ID 读取，不使用综合周榜 Top1。
- 点击 Banner 查看礼物大图、双方信息、活动值和结算周期。
- 切换礼物时同步更新 Banner。
- 非活动礼物或上周无获奖 CP 时不展示 Banner。

## 4. 往期荣誉 Hall of Love

Hall of Love 仅展示已结算结果，内部切换 Weekly、Monthly。

| 页面 | 展示规则 |
| --- | --- |
| Weekly | 展示最近 1 个月内已结算的周榜；最近一周突出展示 Top3，更早各周展示当周 Top1–3 |
| Monthly | 展示最近一个已结算月榜的 Top10；Top1 突出，Top2–3 并列，Top4–10 列表展示 |

## 5. 页面

页面顺序：标题 Weekly CP → 轮播头图 → Ranking / Love Gifts / Hall of Love 三个 Tab。

- 头图从页面顶部延伸至主 Tab，使用四张图片自动轮播。
- 头图 Top1 展示放在右下角，不显示昵称；皇冠居中。
- Ranking：周榜、月榜、倒计时、Rewards、Top3、列表及 My。
- Love Gifts：周期切换、倒计时、Rewards、礼物卡片及当前周期底栏。
- Hall of Love：Weekly、Monthly 往期获奖列表。

## 6. 通用规则与待补配置

- 榜单同分、数值显示和发奖规则沿用[活动榜单通用规则](rules/activity-ranking-common.md)。
- 奖励叠加规则沿用[活动奖励通用规则](rules/activity-reward-common.md)。
- 待补：活动时间、指定关系礼物 ID、展示顺序及关系礼物倍率。
- 待确认：关系礼物倍率是否同步至线上关系榜。
- 待补：各名次奖励资源、有效期、发放对象及曝光时间。
