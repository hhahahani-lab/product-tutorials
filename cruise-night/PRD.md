# 2027 豪华邮轮之夜活动 PRD

## 一、活动配置

活动时区为 UTC+5，正式起止时间待定。活动结束后停止累计和寻宝，保留最终进度、榜单及记录。已达档奖励和待结算榜单奖励按对应规则发放。

收礼航程、送礼寻宝和榜单分别配置装扮。日榜和总榜共用榜单装扮，通过奖励组合和时长区分。重复获奖按[活动奖励通用规则](../rules/activity-reward-common.md)处理。

## 二、活动礼物及计分

| 类型 | 活动礼物 |
| --- | --- |
| 常规 | 跨年烟花（Midnight Fireworks）、皇家邮轮（Royal Cruise） |
| 幸运 | 幸运罗盘（Lucky Compass）、珍珠贝（Pearl Shell）、船舵（Captain’s Wheel）、幸运船票（Lucky Boarding Pass） |

| 礼物范围 | 收礼航程 | 送礼寻宝 | 送礼日榜／总榜 |
| --- | ---: | ---: | ---: |
| 活动常规礼物 | 100% | 100% | 120% |
| 其他常规礼物 | 不计入 | 不计入 | 100% |
| 活动幸运礼物 | 10% | 10% | 10% |
| 其他幸运礼物 | 不计入 | 不计入 | 10% |

活动值＝礼物金币单价 × 数量 × 对应比例。同一笔礼物在每个玩法内按对应比例计算一次，幸运礼物的返奖不增加活动值。活动值最多保留两位小数，小数参与累计、达档及次数兑换。

## 三、Luxury Cruise 每日收礼航程

使用 F 个人收礼单日达档模板。每天累计本人收到的活动礼物价值，依次解锁五站。各站门槛递增，具体数值待配置。

| 站点 | 奖励 | 各项时长 |
| --- | --- | ---: |
| 启航港 Departure Port | 头像框、房间封面 | 1 天 |
| 珊瑚湾 Coral Bay | 头像框、房间封面、房间背景 | 3 天 |
| 星光岛 Starlight Island | 头像框、房间封面、房间背景、房间标签 | 5 天 |
| 烟花之城 Firework City | 头像框、徽章、发言气泡、发言光圈、VIP2 | 7 天 |
| 荣耀港湾 Glory Harbor | 头像框、徽章、发言气泡、发言光圈、VIP2 | 10 天 |

- 各站达成后自动发放该站完整奖励，每站每天一次。一次跨过多站时，每个新达成站点均发奖。达成最高站后当天不再循环。
- 每天 UTC+5 零点重置进度和达档状态。已发奖励及历史记录保留，未达档进度不结转。最后一天在活动结束时截止。
- 房间装扮发至用户对应房间。未创建过房间时跳过该项，之后不补发。其他奖励正常发放。
- 获奖记录保留站点、奖品、时长和获得时间。

## 四、Ocean Treasure 送礼寻宝

使用 E 个人送礼累计抽奖模板。累计本人在活动期间送出的活动礼物价值，每累计满 X 活动值自动兑换 1 次寻宝机会，X 待配置。未兑换余值继续累计。次数和余值均不随日榜或航程重置，活动结束时失效。

| 操作 | 规则 |
| --- | --- |
| 单次寻宝 | 消耗 1 次机会并独立抽取 1 次 |
| 全部寻宝 | 消耗操作发起时的全部可用次数，每次独立抽取。期间新增次数留到下次 |
| 次数校验 | 无可用次数时不可抽取，处理中不可重复发起 |
| 发奖及记录 | 按实际抽中的品类、数量或时长发放，每次抽取单独保存结果和时间 |

抽奖只消耗寻宝次数，航程和榜单活动值继续独立累计。

| 类别 | 奖项范围 |
| --- | --- |
| 个人装扮 | 头像框、徽章、发言气泡、发言光圈、进场飘带、名片框 |
| 座驾 | 豪车座驾，男角色下车登场 |
| VIP | VIP1、VIP2、VIP3、VIP4 |
| 金豆 | 10～100 金豆 |

## 五、Ranking 个人送礼榜

使用两条 D 个人送礼榜规则，按第二节范围及比例独立累计。

| 榜单 | 计分周期 |
| --- | --- |
| 日榜 Daily | 每日 UTC+5 零点重置，当日最晚在活动结束时截止 |
| 总榜 Overall | 活动期累计，活动结束时结榜 |

日榜、总榜各奖励 Top 3，两榜奖励可以同时获得。上榜、同分排序与通用结算规则见[活动榜单通用规则](../rules/activity-ranking-common.md)。

| 名次 | 日榜奖励 | 总榜奖励 |
| --- | --- | --- |
| Top 1 | 头像框、徽章、座驾各 3 天 | 头像框、徽章、座驾各 30 天，VIP7 30 天，冠军靓号 30 天，Banner 和开屏各 7 天 |
| Top 2 | 头像框、徽章、座驾各 2 天 | 头像框、徽章、座驾各 15 天，VIP6 15 天，亚军靓号 30 天 |

榜单座驾以金色游轮为主体，甲板上使用戴金冠的男角色。装扮及 VIP 在对应周期结榜次日发放，靓号和曝光权益按最终兑现配置执行。
