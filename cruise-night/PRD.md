## 三、Luxury Cruise：每日收礼航程

### 3.1 累计与奖励

使用F：个人任务、全部用户、收到礼物、单日统计、各档叠加，不开启循环。每天按第二节比例累计本人收到的活动礼物价值。

五站门槛按当日累计活动值配置，递增；正式门槛待测算，Demo中的1,000／5,000／15,000／40,000／100,000不作为定稿配置。

| 站点 | 奖励 |
| --- | --- |
| 启航港 Departure Port | 头像框1天＋房间封面1天 |
| 珊瑚湾 Coral Bay | 头像框3天＋房间封面3天＋房间背景3天 |
| 星光岛 Starlight Island | 头像框5天＋房间封面5天＋房间背景5天＋房间标签5天 |
| 烟花之城 Firework City | 头像框7天＋徽章7天＋发言气泡7天＋发言光圈7天＋VIP2 7天 |
| 荣耀港湾 Glory Harbor | 头像框10天＋徽章10天＋发言气泡10天＋发言光圈10天＋VIP2 10天 |

- 每站每天达成后自动发放一次完整奖励；单笔跨多站，全部新达成站点均发奖。
- 各站叠加，不按上一站差额配置；最高站达成后当天不再循环发奖。
- 每天UTC+5零点清零航程进度及当日达档状态；未完成部分不结转，已发奖励和历史记录保留。最后一天最晚在活动结束时截止。
- 房间装扮发至用户对应房间。未创建过房间则跳过该项，其他奖励正常发放，之后不补发，沿用F模板规则。

### 3.2 页面与记录

以五站连续航线展示个人进度，默认定位当前航段并展示下一待达站点奖励；全部完成后展示终点。可横向拖动或左右切换查看其他站点，奖励同步切换，查看不触发发奖或改变进度。拖动后停留在所选航段，重新进入玩法时定位当前进度。

当前活动值、所选站点门槛及奖励合并展示；完成后保留满格进度条，不另设完成勾选状态，不重复显示顶部累计数值或“还差多少”文字。

倒计时对应当日重置时间，最后一天取活动结束时间。记录查看本玩法获得的奖励，包含站点、具体奖励名称／类型／天数及完整获得时间。

## 四、Ocean Treasure：送礼寻宝

### 4.1 累计与兑换

使用E：全部用户、送礼任务、活动期累计。仅本人送出的活动礼物按第二节比例累计寻宝活动值。

每X活动值自动兑换1次寻宝机会，X待测算；不足一次的余值持续累计，不每日清零。展示可用次数及“未兑换余值／X → +1 dive”，不另加进度条。次数归送礼用户本人，无需手动兑换。

### 4.2 寻宝操作及结果

| 操作 | 规则 |
| --- | --- |
| Dive once | 消耗1次，独立随机抽取一次结果 |
| Dive all | 消耗点击时已有的全部可用次数，各次独立抽取；操作期间新增次数留到下次 |
| 按钮 | 两个按钮均保留；0次时同时置灰，1次时Dive all等同单次；处理中不可重复触发 |
| 发奖 | 抽中奖励后发放，按实际奖项兑现数量或时长 |

- 获得奖励时标题为Congratulations；上图下天数／数量，同款可叠加装扮与同等级VIP合并显示本次累计天数，同档金豆合并显示数量；不同VIP等级不合并。结果省略开启总次数，点击OK关闭。
- 如最终配置空奖：单次落空显示Sorry、缺省图和Nothing inside；多次省略空奖条目及次数，全部落空仅显示Sorry和OK。空奖配置未定，不因页面留空格推断有空奖。
- 结果可合并，记录仍逐次保存每次实际结果；展示具体奖品名称、类型、数量／天数及时间。
- 活动结束后停止累计、兑换及寻宝，未使用次数和未兑换余值失效，不结转。
