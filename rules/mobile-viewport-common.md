# 移动端页面容器与滚动约定

- 状态：用户明确确认的长期设计默认；既有页面是否全部实现尚未验证，不作为上线事实。
- 来源：本次对话，用户要求统一并长期复用。
- 范围：本项目移动端原型及其浏览器展示，包含主页面、Tab 内容和二级页；具体页面有明确不同要求时按当次要求。

1. 页面容器占满当前设备可视屏幕，高度随可视区域变化，不写死设备像素高度，也不随正文长度撑开整个页面。
2. 顶部导航固定，剩余正文区域内部滚动；切换 Tab 或进入二级页时沿用相同容器结构。
3. Inviter 邀请按钮、Ranking 的 My 栏固定底部，正文为底部区域和安全区留出空间，末项可完整滚动到可见位置。
4. 弹窗限制最大可视高度，长内容在弹窗内滚动，操作区按对应弹窗规范处理，不因正文变长覆盖整页。
5. 浏览器版保持同样结构；视口、浏览器工具栏或方向改变时适配可视区域，避免页面忽长忽短。
6. 隐藏滚动条外观仍保留触摸、鼠标及必要键盘滚动；不能通过禁止滚动代替隐藏滚动条。

验收：短/长内容、主/二级页、Tab切换、底部操作/本人栏、长弹窗、不同视口；分别核对容器稳定、正文可滚动、固定区域无遮挡。不将本记录视为页面已经修改或实际验收通过。
