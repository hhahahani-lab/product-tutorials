# 活动页规则弹窗通用约定

- 状态：2026-10-23用户明确确认，作为后续设计默认约定；上线状态未确认。
- 来源：用户确认的活动规则弹窗设计约定。

1. 不设置 Got It / 知道了 等底部确认按钮。
2. 关闭按钮叠在弹窗右上角，不占独立标题栏，不遮挡Tab或正文。
3. 原规则与奖励合并展示时采用Rules / Rewards两个Tab，不重复展示弹窗标题。2026-11-16起，Yaloka活动页默认按[活动Demo约定](activity-demo-common.md)设置独立Rule入口和榜单奖励入口，不能机械在Rule弹窗内重复增加Rewards；榜单奖励弹窗内切换对应榜单周期。
4. 隐藏滚动条，保留内容上下滑动。
5. 移动端页面文案使用英文。

6. 弹窗默认居中，高度约为屏幕可视高度的75%，避免几乎覆盖整页；长内容在弹窗内滑动，滚动条隐藏。移动端使用动态视口高度适配。

后续活动页规则弹窗优先复用以上约定；具体活动另有明确要求时，以当次要求为准。

2026-11-16补充：Rule入口位于头图下方与活动模块交汇处、贴右边缘，使用横向文字按钮；Rule暂不提供概率。Records使用紧凑文字记录，时间完整到秒，不单独标时区；适用范围及其他入口规则见活动Demo约定。
