| --- | --- |
| [活动Demo页面](activity-demo-common.md) | 沉浸式导航、Rule／记录／奖励入口、礼物专区、精简文案、档位切换、抽奖次数与结果、奖励展示、Records格式、四格倒计时 |
| [活动榜单](activity-ranking-common.md) | 前50名展示、Top3／My、在房跳转、同分排序、数值格式、周期切换、结榜发奖 |

## 榜单数值规则摘要

所有榜单活动值（Top3、列表、My）一致处理：不超过9,999,999显示原值；超过才除以1,000，保留1位小数、向下取整，单位小写k，不使用M。例如10,000,000显示10000.0k。完整口径以[榜单规则](activity-ranking-common.md)为准。

## 维护

- 规则正文只在本目录维护；其他活动文档引用统一文件，不另建正文副本。
- 活动PRD保存具体业务参数，不将单次活动值写成通用默认。
- 当前修订日期：2026-11-23。具体活动明确的特殊要求优先。
