# Yaloka IM 活动入口与活动通知 PRD

V1 · 适用范围为 Yaloka App 的 IM。交互见 [IM 活动 Demo](index.html)。

## 1. 活动 Tab

- 在 IM 顶部新增 `Events`，与 `Message`、`Contacts` 同级，位于 `Contacts` 之后。
- 展示当前进行中、且对该用户可见的所有活动 Banner。活动开始后进入列表，下架时移出列表。
- 每张 Banner 下方展示距活动结束的倒计时，以活动配置的结束时间和校准后的服务端时间为准。倒计时实时更新，显示到分钟，例如 `Ends in 2d 05h 30m`，不足 1 分钟时显示 `Ends in <1m`。到达活动结束时间后，卡片自动移出列表。
- 点击卡片进入对应活动页，返回后回到 `Events` 列表。活动开始时间在活动详情查看。
- 当前没有可见的进行中活动时，保留 `Events` 入口，展示 `No ongoing events`。

## 2. 活动通知会话

- 活动站内通知统一由官方账号 `Event Notices` 发送并归入同一个会话。在 `Message` 列表中，`Event Notices` 固定展示在 `Yaloka Team` 正下方，首次收到通知前即可进入。
- 会话列表展示账号头像、名称和 `Official` 标签。有通知时展示最新消息摘要、时间和未读数，进入会话后沿用 IM 的已读规则。没有通知时，进入会话展示 `No event notices`。
- 二级页为只读会话。标题栏仅展示居中的 `Event Notices` 和左侧返回按钮。消息按现有系统会话样式展示，消息左侧使用该账号头像。
- 活动结束或从 `Events` 下架后，已发送的通知仍可在会话里查看。

| 通知类型 | 发送规则 | 消息样式与操作 |
| --- | --- | --- |
| 活动开始 | 活动正式开始时，发给该活动指定的接收对象。 | 展示活动 Banner。点击进入对应活动页。 |
| 活动结束 | 活动到达结束时间时，发给该活动指定的接收对象。 | 展示活动 Banner 和 `Event ended` 状态，整条消息无跳转。 |
| 获得奖励 | 发给获奖用户。通知写明奖励已到账时，以实际发放成功为触发条件。 | 使用文本气泡，写明活动和获得的奖励。有对应页面时，在气泡内展示 `Click to view` 并跳转到结果页或奖励记录。纯文本消息无跳转入口。 |
