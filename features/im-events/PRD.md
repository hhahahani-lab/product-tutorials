# Yaloka IM 活动入口与活动通知 PRD

V1 · [交互 Demo](index.html)

## 1. 活动 Tab

- IM 顶部在 `Contacts` 后新增 `Events`，展示该用户可见的所有进行中活动 Banner。活动结束或下架后移出，列表为空时显示 `No ongoing events`。
- Banner 下方按服务端时间实时显示结束倒计时，精确到分钟，如 `Ends in 2d 05h 30m`。不足 1 分钟显示 `Ends in <1m`。
- 点击 Banner 进入活动详情，可查看开始时间。返回时回到列表。

## 2. 活动通知会话

- 官方账号 `Event Notices` 统一发送活动站内通知。会话固定在 `Yaloka Team` 正下方，空会话也可进入，显示 `No event notices`。
- 列表和消息沿用官方会话样式及 IM 已读规则。会话只读，标题栏仅保留左侧返回键和居中标题。活动结束或下架后，历史消息仍可查看。

| 通知 | 发送 | 展示与跳转 |
| --- | --- | --- |
| 活动开始 | 开始时发给活动指定对象 | Banner，点击进入活动 |
| 活动结束 | 结束时发给活动指定对象 | Banner 和 `Event ended`，无跳转 |
| 获得奖励 | 发给获奖用户，到账通知在发放成功后发送 | 文本气泡写明活动和奖励。有结果页或奖励记录时显示 `Click to view` |

**待确认**　结束通知是否默认只发给实际参与用户。
