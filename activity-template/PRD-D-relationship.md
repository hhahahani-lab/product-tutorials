# 模板 D：亲密关系榜扩展 PRD

## 一、模板类型

模板 D 新增「榜单类型」单选：个人榜／亲密关系榜。旧规则默认个人榜。个人榜和亲密关系榜的发奖方式均固定全发、只读展示。个人榜统计口径仅支持送出／收到礼物；历史双向配置编辑时须重新选择，不静默改为某一种口径。

## 二、亲密关系榜配置

| 字段 | 规则 |
|---|---|
| 规则名称、规则说明 | 沿用现有字段 |
| 榜单类型 | 亲密关系榜 |
| 参与对象 | 固定为有有效 CP／密友关系的全部用户 |
| 统计周期 | 单日／单周／单月／活动期累计，单选 |
| 业务时区 | 固定 UTC+5 |
| 统计口径 | 固定仅统计 CP／密友关系双方互送礼物，只读展示 |
| 发奖方式 | 固定全发 |
| 礼物范围 | 全部礼物／指定礼物，支持配置，均包含背包礼物 |
| 统计指标 | 固定亲密值 |
| 默认常规礼物计分 | 每 1 金币礼物面值计 1 亲密值 |
| 默认幸运礼物计分 | 金币礼物面值按 10% 计入亲密值 |
| 展示数量 | 前 50 对关系 |

榜单按每段关系排名；排名单位、展示数量、底部「我的」选取及关系周期处理属于业务规则，不单独放在后台配置表单中。固定计分口径、指标及发奖方式只读展示。指定礼物支持多组 ID 与对应比例，同一 ID 不可组内或跨组重复。

指定礼物模式新增「其他礼物也计入」开关，默认关闭；开启后，未指定常规礼物按 100%、未指定幸运礼物按 10% 计入，关闭则均不计入。指定礼物始终使用所在组比例，每笔只计算一次，不叠加。旧配置未设置此开关时按关闭处理。

个人榜与亲密关系榜统一使用「全部礼物／指定礼物」「多组礼物 ID」「其他礼物也计入」配置。个人榜保留送出／收到口径，以及按礼物个数／按金币价值两个统计指标。

- 按金币价值：与亲密关系榜共用指定比例优先、其他常规礼物 100%／幸运礼物 10% 的折算配置。
- 按礼物个数：仍按实际个数累计，不使用金币折算比例；指定模式可配置多组 ID，开启其他礼物时未指定礼物也按实际个数计入。切换统计指标不清空已填写的礼物或比例。
- 旧个人榜的指定礼物 ID 编辑时回显为一组，指定比例默认 100%，其他礼物开关默认关闭；未编辑保存前不改写原配置。
- 关系榜固定亲密值，不使用个人榜的礼物个数或个人送收礼口径。

## 三、计分与排名

- 接入现有亲密关系服务，使用真实关系类型、有效状态和关系周期。
- 只统计有效关系双方互相送礼的行为，A→B 与 B→A 合并计入同一段关系；向关系外用户送礼不计入。
- 按当前活动、规则、榜单统计周期和关系周期累计，旧关系积分不转入新关系。
- 同一用户可以有多段关系，各段关系按实际亲密值分别上榜，不限制上榜关系数量。
- 关系解除后不再发放该关系奖励；榜单定时过滤已解除关系，发奖时再次校验关系有效性。
- 双方重新建立关系时，按新的关系周期从零累计，不继承旧关系数据。重建不能恢复旧关系的发奖资格。
- 周期边界、同分排序和亲密值精度沿用线上关系榜单口径，不引入个人榜的差异规则。

## 四、展示

- Top3 卡片、前 50 对列表、底部「我的」均展示关系双方信息和该段关系亲密值。
- 底部「我的」仅显示本人排名最高的一段关系，列表仍正常显示各段关系。
- 支持日／周／月／活动期累计周期切换与对应结算倒计时，按后台实际配置展示。
- 在房状态、房间跳转与活动值格式化复用已有通用能力；未上榜及空榜展示沿用线上关系榜单规则。

## 五、双人奖励

沿用模板 D 的奖励配置字段：Min 名次、Max 名次、奖励类型、奖励 ID、数量／等级／时长、适用性别、奖励说明。

- 发奖方式固定全发，每项奖励按适用性别分别匹配关系双方。
- 适用性别「不限」：双方各发一份该项奖励。
- 适用性别「男／女」：仅向符合该性别的关系成员发放；双方均符合时分别发放。
- 全发模式不配置随机权重或空奖，不把配置数量按双方拆分。
- 发奖时校验原获奖关系周期仍有效；已解除关系不发奖，重新建立的关系不代领旧周期奖励。
- 发奖结果按关系周期、统计周期、奖项和接收人去重；失败仅补发失败项，避免重复发放或叠加时长。

## 六、前端与接口封装

后台配置 D 亲密关系榜 → 前端传活动 ID → 加载对应规则、周期配置、双人榜单、本人最高排名关系和奖励数据。

前端按榜单类型渲染个人／双人结构。计分、关系过滤、排名、本人最高关系选取及双人性别匹配发奖由服务端处理，主题素材和标题按活动替换。

## 七、Demo 范围

后台 Demo 实现类型切换、字段显隐与锁定、配置保存回显及双人奖励配置说明；真实关系服务、榜单统计与发奖由研发接入，不因原型展示而视为已上线。
