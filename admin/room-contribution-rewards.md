# Yaloka 房间贡献周奖励调整 PRD

适用于 Yaloka 房主。生效周待确认。

## 周奖励规则

- 按 UTC+5 统计和结算，每个达标房间每周生成一条奖励记录。
- **贡献 Coins**为当周房间收礼的有效 Coins 合计，普通礼物计 100%，幸运礼物计 10%。**房间有效麦时**为当周房内所有用户的有效上麦时长之和。
- **发奖档位**取贡献 Coins 和房间有效麦时同时达到的最高档。任一项低于 Lv1，当周无奖励。违规房间取消获奖资格并记录原因。
- **发放**在每周二自动进行，按上周最终发奖档位向房主账户发一笔 Coins。

## 后台房间贡献奖励

入口为「活动奖励 → 房间贡献奖励」。列表展示当周双达标房间的奖励记录，取消获奖资格后保留记录。

- **奖励明细**展示贡献 Coins、贡献档位、房间有效麦时、麦时档位、发奖档位、Coins 奖励、获奖资格和发放状态。发放状态为待发放、已发放或发放失败，失败时显示原因。取消获奖资格时，发奖档位、Coins 奖励和发放状态均显示「—」。
- **筛选**支持奖励周期、发奖档位、获奖资格和发放状态，可搜索房间 ID、房间名称或房主。发奖档位可选全部、Lv1–Lv7 或「无发奖档位」，其中「无发奖档位」仅包含已取消获奖资格的房间。
- **排序与导出**支持按贡献 Coins 或房间有效麦时升降序。首次点击表头按数值降序，再次点击切换方向，同值按房间 ID 升序。当前查询结果先全量排序再分页，CSV 按相同顺序导出全部匹配记录。
- **顶部统计**按当前奖励周期、运营视角和筛选条件汇总全部匹配记录。「已发奖房间数」按发放成功的房间计数，「已发金币数」汇总这些房间已发放的 Coins。没有已发放记录时，两项均显示 0。
