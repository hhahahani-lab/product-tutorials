# 薪资后台批量导入 PRD

在「结算对账」选好期次，直接点「批量确认打款」或「批量发放金币」打开导入弹窗。

**名单填写**

- 代理周结算填「代理信息」里的 UID 和「代理总结算」的美元金额。
- BD+月结算填「成员信息」里的 UID 和这张月账单的美元结算金额。

**导入与确认**

上传 CSV 后，后台用 UID 和金额在当前期次找原账单，列出找到的账单和这次要处理的明细。金额合计把这些原账单的美元金额加起来，每张只算一次。没匹配上的行显示原因。

- **批量确认打款**只导入外部转账成功的名单。点「确认已打款」，对应款项标为已付款。
- **批量发放金币**导入待发名单。先看每笔金币和金币合计，再点「确认发放金币」发放。
