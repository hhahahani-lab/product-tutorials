# 薪资后台批量导入 PRD

在「结算对账」选好期次，无需勾选账单，直接点「批量确认打款」或「批量发放金币」。

## 名单填写

CSV 填两列，用户 ID 和原账单结算金额（USD）。

- 代理周结算填「代理信息」里的 UID 和「代理总结算」金额。
- BD+ 月结算填「成员信息」里的 UID 和原月账单的结算金额。

后台按 UID 和金额匹配当前期次的账单。金额合计按匹配到的原账单金额加总，每张只算一次。没匹配上的行显示原因。

## 批量确认打款

导入外部转账成功名单，弹窗直接显示结算列表里匹配到的原账单，沿用原表头、顺序和数据。核对后点「确认已打款」，对应现金款项标为已付款。

## 批量发放金币

导入待发名单，弹窗显示每笔发放明细和金币合计。核对收款账号和金币数后点「确认发放金币」，发放成功后更新付款状态。
